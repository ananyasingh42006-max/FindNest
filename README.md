# FindNest 🔎

## Campus Lost & Found Board

FindNest is a campus-based Lost & Found web application designed to help students report, search, and recover lost or found items within their college campus.

The application provides a simple and user-friendly platform where students can post details about lost or found belongings, browse available posts, and search or filter items based on type and location.

## Features

- 🔐 Firebase Authentication
- 📌 Post lost and found items
- 🔍 Search for lost or found items
- 🗂️ Filter items by type and location
- 📋 Browse items using organized cards
- ☁️ Store data using Cloud Firestore
- 🌐 Deployed using Firebase Hosting
- 📱 Simple and user-friendly interface

## Technologies Used
